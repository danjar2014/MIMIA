# Petits Robots : apprendre la robotique et le code (6-12 ans, en français)

Application web installable (PWA), hors ligne. Aucun matériel nécessaire : le robot est simulé.
Lancer : start.bat (http://localhost:8082). Test des niveaux : `node test-levels.mjs`.
Pour installer sur tablette : héberger le dossier en HTTPS puis "Ajouter à l'écran d'accueil".

## Trois tranches d'âge (au choix au démarrage, modifiable)
- 6-8 ans : séquences d'instructions (avancer, tourner), sans texte à écrire.
- 8-10 ans : boucles (répéter), angles, formes géométriques.
- 10-12 ans : conditions (si), boucles conditionnelles (tant que), fonctions (Mon bloc), variables (taille).

## Contenu
- Découvrir le robot : 7 parties (cerveau, yeux, capteur de lumière, lampe, roues, batterie, haut-parleur) en leçon en 3 temps ; puis "capteur -> cerveau -> moteur" (sentir, penser, agir).
- Construire (la carte du robot) : une carte électronique avec des emplacements. On pose les éléments (batterie, moteurs, lampe, haut-parleur, capteur de distance, capteur de lumière, bouton) depuis le tiroir, puis on les relie au cerveau avec des fils en touchant deux points. Points colorés par famille (rouge = énergie, bleu = capteurs/entrées, vert = actions/sorties). 9 niveaux : l'énergie, les roues, la lampe, les yeux du robot, veilleur de nuit, robot alarme, plus et moins (polarité), robot explorateur, carte libre. Le robot réagit en direct, avec la liste "Ce que fait ton robot". Tests : `node test-board.mjs`.
- Programmer le cerveau (dans Construire) : 5 niveaux 🧠 (bouton→lampe, robot prudent, lampe qui clignote, deux capteurs, alarme à deux niveaux) où l'enfant écrit lui-même le programme du cerveau avec des blocs « si … alors … sinon » et des ordres (allumer la lampe, faire rouler les roues, faire sonner…). Le cerveau relit le programme à chaque tour : tout est éteint, puis les blocs sont lus de haut en bas. Les blocs lus s'allument en jaune ; un test lance plusieurs situations et montre la première qui échoue. Aussi disponible dans la carte libre (bouton « Cerveau : automatique / je le programme »). Tests : `node test-prog.mjs`.
- Aller plus loin (20 activités) : adapté du cours « Codage robotique, unité 12 » (NovaSavo, novasavo.com), reformulé et rendu interactif pour 6-12 ans.
  - ROS : fiches (nœuds, sujets, publier / s'abonner, services, fichier de lancement), quiz « mythe ou réalité », laboratoire de nœuds (brancher caméra → planificateur → moteurs avec des sujets, puis plusieurs abonnés), premier nœud « Hello World » en blocs, télécommande (le programme publie des messages, le robot écoute /cmd).
  - Apprentissage automatique : les 4 familles, le bras qui apprend par essais (renforcement, avec adaptation quand la pièce bouge), apprendre avec des exemples (supervisé : choisir des exemples variés), étapes d'un projet d'IA, bonnes habitudes.
  - Les 4 niveaux d'autonomie de l'IA, règles codées ou apprentissage ?, secteurs d'application et chiffres du cours, métiers, parcours d'apprentissage, démarrer avec ROS. Tests : `node test-adv.mjs`.
- Programmer : 17 niveaux sur grille (6 + 5 + 6). Chaque niveau introduit une seule idée nouvelle. Aux niveaux 10-12, un même programme doit réussir plusieurs parcours (généralisation).
- Capteurs : lumière (observer puis écrire la règle si/alors), distance (observer puis régler le seuil de freinage).
- Créer : dessiner avec le robot (défis avec modèle gris à recouvrir, ou dessin libre), composer une danse (lumières, notes, sauts), dessiner son propre parcours puis le programmer.
- Mon robot : personnaliser (nom, couleur, tête, yeux, antenne). Mes créations : tout se garde et se rejoue.

## Méthode Montessori appliquée
- Du concret vers l'abstrait : on découvre le robot réel avant de le programmer ; le programme est visible (blocs) et le robot l'exécute pas à pas, bloc surligné.
- Une difficulté à la fois, niveaux isolés.
- Contrôle de l'erreur intégré : pas de note ni de punition ; le robot montre son chemin (petits pas, ❗ sur l'obstacle), le modèle gris se superpose au dessin, indice sur demande.
- Liberté et rythme propre : tous les niveaux restent accessibles, le niveau conseillé est entouré ; création libre.
- Pas de score, pas de chrono. Pause respiration, rappel de pause doux, mode calme, grand affichage, voix.

## Première configuration par un parent (obligatoire)

- Au tout premier lancement, l'enfant n'a accès à rien : un **parent** doit d'abord répondre à une question d'adulte (une multiplication), choisir son **code parent** à 4 chiffres (codes trop faciles refusés : 0000, 1234…), noter son **code de secours**, puis régler le **profil de l'enfant** (prénom, tranche d'âge, objectif du jour, ce que la voix lit, temps de jeu par jour).
- Un écran « Abonnement » annonce la version gratuite ; la gestion de l'abonnement (phase suivante) se fera depuis cet espace parent.
- Ensuite l'enfant retrouve Bolt, qui ne redemande ni le prénom, ni l'âge, ni l'objectif (déjà réglés par le parent) : il propose seulement le test de niveau et le parcours.
- Tous les réglages et le tableau de bord demandent le code parent à chaque ouverture. Le code ne peut plus être retiré, seulement changé. « Code oublié » : code de secours, ou effacement total réservé aux adultes (question de calcul).
- Appareil déjà utilisé avant cette version : la configuration parent est demandée une fois, la progression de l'enfant est conservée.
- Voix selon l'âge (réglage « Selon l'âge ») : 6-8 et 8-10 ans = consigne et résultat à voix haute (les 6-8 ans entendent aussi les réponses, plus lentement) ; 10-12 ans = seulement avec le bouton 🔊.
- Test : `node test-parentsetup.mjs`.

## Mode test (tout débloqué)

- `parcours.js` : `FLAGS.testUnlock = true` débloque toutes les aventures, étapes et cartes, et affiche le bandeau « 🧪 Mode test : tout est débloqué » sur l'accueil.
- **Pour la mise en production : passer `testUnlock` à `false`** (le blocage réel revient). Les tests le coupent eux-mêmes.

## Indices qui s'adaptent (inspiré de l'analyse de CodeMonkey)

- `hints.js` : le bouton 💡 de la grille de blocs donne 4 indices de plus en plus précis, calculés sur ce que l'enfant a déjà posé : ① où est le but (« 2 cases vers le bas et 3 cases vers la droite »), ② ce que fait SON programme (cogne un caillou, tourne en rond, s'arrête à N cases du drapeau, étoile oubliée, « il marche déjà : lance-le »), ③ le prochain bloc à changer (« Au bloc 2, essaie tourner à droite »), ④ une solution regroupée (« avancer 3 fois, tourner à droite… »).
- Une solution est calculée automatiquement (plus court chemin) : l'indice marche aussi sur « Dessine ton parcours », qui n'a pas de solution écrite (le bouton 💡 y plantait avant).
- Test : `node test-hints.mjs`.

## S'entraîner : parcours aléatoires (inspiré du « Skill Mode » de CodeMonkey)

- Menu « Programmer le robot » → 🎲 **Parcours surprise** : un parcours tiré au hasard (`practice.js`), toujours réalisable (le plus court chemin est calculé avant de le proposer, avec au moins un virage), puis un autre à chaque réussite (« Niveau suivant »).

- Test : `node test-practice.mjs` (720 parcours vérifiés : bien formés, réalisables, solution juste, difficulté croissante).

## « Qui joue ? », confirmations ✖/✔ et espace parents en icônes (inspiré de l'observation d'iwawa)

Utilisées pour effacer la progression, effacer les statistiques et l'effacement total (code oublié, qui garde en plus la question d'adulte).

Chaque icône ouvre un petit écran de quelques réglages ; « Suivi » ouvre le tableau de bord ; ✖ ferme. Le réglage de la limite de jeu par jour est maintenant dans « Temps ».

## Voix enregistrée : une femme (F5)

- Une seule voix française, sans accent, générée en local avec VoiceStudio : **F5 = femme** (CosyVoice 3, timbre cloné depuis `voice/tools/ref_F5.wav`). Aucun choix à faire : ni écran de choix, ni réglage de voix (la voix d'homme a été retirée). Chaque phrase de l'appli a un petit mp3 (`voice/clips/f5/<clé>.mp3`, listés dans `voice/manifest.json`).
- Lecture : `voiceclips.js` découpe le texte en phrases et lit le clip de chaque phrase ; une phrase sans clip (chiffres, ou pas encore générée) est lue par la voix de l'appareil. **Le prénom de l'enfant est toujours lu par la voix de l'appareil** (pas de clips de prénoms : il peut être n'importe lequel). 🔇 coupe aussi les clips.
- Fabrication : `node voice/extract.mjs` (extrait les phrases du code → `voice/phrases.json`, plus `voice/phrases_extra.json` écrit à la main) puis `python voice/gen.py` (VoiceStudio lancé sur le port 3900 ; reprenable). La clé d'une phrase est la même en Python (`gen.py`) et en JS (`voiceKey`).
- La voix est aussi gardée comme skill Claude (`voix-francais-f5-m4`) pour les prochains projets.
- Test : `node test-voiceclips.mjs`.

## Joueurs, compliments, puzzle, plein écran (nouveautés)

- **Plusieurs joueurs** : le parent en ajoute, règle ou retire (Espace parents → Joueurs : prénom, fille/garçon, âge, objectif). Réglages communs (code, voix, écran…) ; progression, robot et statistiques propres à chaque enfant. « Qui joue ? » montre tous les joueurs ; l'ancien joueur unique devient le joueur 1 (rien ne se perd). Test : `node test-profiles.mjs`.
- **Fille ou garçon** (obligatoire dans la configuration parent) : `praise.js` donne des compliments avec le prénom, accordés (« tu es une championne » / « un champion ») et différents selon l'âge. Le « Bravo ! » des messages de réussite devient « Bravo, Léa ! », et le petit robot dit aussi le prénom. À l'accueil la voix dit « Bonjour Léa ! ».
- **Bruitages du robot** : avancer, tourner, sauter, cogner (`sfx()` dans `util.js`, sons synthétisés).
- **Puzzle du robot** (tuile « Puzzle ») : 2×2, 3×3 ou 4×4 morceaux selon l'âge, 6 dessins, 20 XP. Test : `node test-puzzle.mjs`.
- **Suivi** : le retour ramène à l'espace parents. **Cadenas parents** : fixe en haut, hors des cartes.
- **Plein écran verrouillé** (Espace parents → Écran) : sur Android l'écran est épinglé (la sortie demande les gestes système ; le verrou se retire avec le code parent dans l'appli) ; sur le web, plein écran.

## Les petits (3-6 ans), cartes des parents, animation d'entrée, salutations

- **Catégorie « 3 – 6 ans »** (choix du parent : configuration ou Espace parents → Joueurs) : un accueil de gros mots-icônes, sans texte à lire, la voix lit tout ce qu'on touche. Sept activités (`petits.js`), toutes dans l'univers des robots, 5 petites manches chacune : **Chiffres** (compter des engrenages, piles, lampes), **Lettres** (« R comme robot »), **Couleurs** (touche le robot rouge), **Jours** et **Mois** (ce qui vient après, puis l'ordre), **Relier** (chaque objet à son ombre), **Espace** (la lune, la fusée ; haut, bas, gauche, droite), plus le **Puzzle** 2×2 et **Mon robot**. 10 XP par activité. Test : `node test-petits.mjs`.
- **Niveaux cachés selon l'âge** : un enfant ne voit jamais les niveaux des plus grands (blocs, code, construction, capteurs, « Plus loin », Grand Projet). Le parcours ne montre que les étapes de son âge (`stepVisible` dans `parcours.js`) ; « Plus loin » n'existe pas pour les 6-8 ans. Les parents changent la tranche d'âge quand l'enfant progresse.
- **Mode test supprimé** : plus de bandeau « tout est débloqué ». Les parents gardent **Espace parents → Cartes** : pour chaque carte de l'accueil, ✨ selon la progression, 🔓 toujours ouverte ou 🔒 bloquée (réglé par enfant), et « Tout débloquer » dans Parcours.
- **Animation d'entrée** (`splash.js`) : le robot de l'enfant arrive en volant dans l'espace (étoiles, planète, lune), un toucher la passe ; en mode calme elle est presque immédiate. Pas d'animation juste après un changement de joueur.
- **Salutations selon l'heure** : « Bonjour / Salut / Content de te revoir, Léa ! » le jour, « Bonsoir… » le soir, lues par la **voix de l'appareil** (marqueur invisible `DEVICE` dans `util.js`) pour éviter la cassure entre deux voix.
- La voix de l'appareil remplace aussi les mots seuls (les clips d'un mot seul étaient ratés) : `voice/gen.py` n'en génère plus.
